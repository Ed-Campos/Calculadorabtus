# Dimensionamento de BTUs

Calculadora de ar-condicionado (Hi-wall, piso-teto, cassete e multisplit) com clima por cidade e resultado em PDF.

Site estático em um único arquivo: `index.html`. Sem build, sem dependências.

## Rodar localmente
Abra o `index.html` no navegador, ou: `npx serve .`

## Publicar
Importe o repositório na Vercel (Framework Preset: **Other**, sem build command, output na raiz).

## Ajustes
Capacidades por tipo, margem técnica e fatores de cálculo ficam no bloco `CONFIG` dentro do `index.html`.
